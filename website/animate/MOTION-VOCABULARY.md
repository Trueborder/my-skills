# Web motion vocabulary

Use this reference when someone describes an effect and wants a term to search for or use in a brief. Match the visible behavior before prescribing an implementation.

| What happens | Common term |
|---|---|
| Opacity rises or falls | Fade in or fade out |
| Two views trade opacity at the same time | Crossfade |
| A menu grows slightly from its anchor as it appears | Pop in or scale-and-fade |
| A mask uncovers the content from an edge | Wipe or reveal |
| Items begin the same motion at successive offsets | Stagger |
| An element moves from its old layout position to the new one | Layout transition. FLIP is one implementation technique |
| A card becomes a full detail view while keeping visual continuity | Shared-element transition |
| A button briefly shrinks when pressed | Press feedback |
| A loading highlight travels across a placeholder | Skeleton shimmer |
| Scrolling directly drives the progress of an effect | Scroll-linked animation |
| Entering the viewport starts an effect | Scroll-triggered animation |
| Layers scroll at different speeds | Parallax |
| An element travels past its resting position before returning | Overshoot |
| Dragging against a boundary meets elastic resistance and then rebounds | Rubber-banding |
| A drag continues after release according to pointer speed | Momentum or inertia |
| A moving element smoothly changes target mid-flight | Retargeting or interruption |
