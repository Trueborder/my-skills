# Check: voice

For public Novaryn and LongJumpReplay pages, use plain English or natural Czech according to the page language. Lead with the user's task and concrete product behavior. Keep a calm, practical tone. First person is appropriate on the About page; product and account pages should speak directly to the user and use concise labels.

Avoid stacked abstract promises, generic agency language, unsupported superlatives, repeated scene-setting, and promotional claims that do not help a user decide or act. Keep technical terms when they name the actual platform or workflow. Match each page's existing English/Czech language convention and preserve meaning across translations.

## Grading

Aligned means clear, direct copy with an appropriate register and accurate translations. Drift means generic or repeated copy without a false claim. Misaligned means misleading persuasion, an inappropriate register for an account/security flow, or a language mismatch that blocks understanding.
