# My Skills

A collection of reusable agent skills organized by purpose.

- [Website](website/) contains frontend design, UI, motion and web experience skills.
- [General](general/) contains planning, writing and dashboard skills.
- [Starter guide](STARTER-GUIDE.md) explains how to use the collection.

Each skill has its own directory containing a SKILL.md and any supporting files. Add further categories alongside website and general. Upstream licenses are included where provided. Individual skills may contain additional license terms.
