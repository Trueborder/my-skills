# Codex Skills pro začátek

Dvanáct skillů pro člověka, který chce s Codexem hlavně stavět weby a občas psát texty nebo navrhnout dashboard. Kopíruj celou složku každého skillu včetně jeho podpůrných souborů.

## Zkus tyhle čtyři jako první

| Skill | Příklad zadání |
| --- | --- |
| brainstorming | S $brainstorming se mnou vyjasni první verzi webu pro náš klub. |
| frontend-design | S $frontend-design navrhni a postav jednoduchou přihlašovací stránku v našem stylu. |
| impeccable | S $impeccable audit zkontroluj přístupnost a mobilní zobrazení mé stránky. |
| humanizer | S $humanizer:humanizer uprav text na stránce O nás a zachovej všechny ověřené údaje. |

## Přidej podle toho, co děláš

| Skill | Kdy se hodí |
| --- | --- |
| design-taste-frontend | Když děláš nový veřejný web nebo měníš jeho vizuální směr. Pro automatické kontroly potřebuje Node.js 22+ a Chrome, Edge nebo Chromium. |
| animate | Když chceš přidat nebo zkontrolovat přechod, odezvu tlačítka nebo gesto. |
| animation-performance | Když se pohyb trhá a chceš zjistit příčinu. |
| mobile-native | Když se web na telefonu špatně ovládá, zoomuje vstup nebo má nesprávnou výšku. |
| break-ui | Vyvolej přes $break-ui, když chceš zkusit dlouhá jména, prázdný seznam a další hraniční data. |
| prototype | Vyvolej přes $prototype, když chceš předem porovnat několik různých variant komponenty. |
| article-writing | Když potřebuješ srozumitelný článek, návod nebo newsletter ve vlastním stylu. |
| dashboard-builder | Když chceš sestavit přehled z metrik pro lidi, kteří z něj mají něco rozhodnout nebo udělat. |

## Jak je použít v projektu

1. V kořeni vlastního projektu vytvoř .agents/skills.
2. Ze startovací sady do ní zkopíruj celé složky vybraných skillů. Výsledná cesta může být .agents/skills/frontend-design/SKILL.md. Složku licenses ponech s balíčkem nebo ji přilož jako .agents/licenses.
3. Otevři nový chat v adresáři svého projektu. Do zadání napiš třeba „Použij $frontend-design a navrhni stránku pro přihlášení.“
4. Impeccable při prvním použití může potřebovat stáhnout svůj ověřovaný engine. Pokud není dostupný, jeho návod popisuje ruční práci s kontextem projektu.

Sada je výběr lokálních skillů s konsolidovanými verzemi animate, impeccable a humanizer. Přiložené licence a uvedení autorů ponech při dalším předávání.
